# Linux support implementation plan

Goal: Linux native x64 setup, status and uninstall plus AppImage release.
Architecture: reuse System, Change, journal and IPC. Use keyring Secret Service and secret-tool for shell/login retrieval, systemd user environment for manager-launched processes, XDG autostart for login refresh. No keys in files. Existing processes and desktop launchers outside systemd do not inherit changes automatically.
Tech stack: Rust/Tauri, existing keyring with Linux backend, bash/zsh/fish, systemd, GitHub Actions.

User authorized full Linux setup including key, config, environment and uninstall. Builder choices: Linux x64 AppImage; require Secret Service, secret-tool and systemd user session. No WSL/headless support. No real credential/config mutation during verification. No new release/tag in this task.
